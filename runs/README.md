## Reading a ledger

`ledger.md` is the human-readable receipt table; `ledger.json` carries the
full `action_text` per entry, which is what you need to reproduce a
verdict yourself (see `verify_yourself.md` — copy the string verbatim).

Verdicts: `SAT` permitted · `UNSAT` blocked, action never executed ·
`SKIPPED` non-governed (reads/searches, screened by the guard, no paid
check) · `OUTAGE-BLOCKED` API unreachable after retries, fail-closed ·
`EXTRACTION-BLOCKED` the check returned a permit whose required variables
were missing, so it was not sound to act on (`BATTLE-TEST-FINDINGS.md` §2).
